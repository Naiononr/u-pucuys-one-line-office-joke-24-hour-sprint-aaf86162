One short joke about office life, written for make.fun's One-Line Office Joke: 24-Hour Sprint bounty. The program writes a single fixed line to `/output/entry.txt`:

> The meeting could have been an email, the email could have been a Slack message, and the Slack message could have been silence.

## Run it

```sh
node main.ts
```

Deterministic, stdlib only, no network. Set `MAKEFUN_OUTPUT_DIR` to choose where `entry.txt` is written (defaults to `/output`).
